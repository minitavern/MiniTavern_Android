## 核心功能

- **完整支持 SillyTavern 角色卡**  
  轻松导入 SillyTavern 的 .png 或 .json 角色卡（含内置示例、社区分享，支持图片/URL 导入）。

- **广泛兼容 AI 模型**  
  可连接主流服务商，包括：  
  - OpenAI（ChatGPT）  
  - Anthropic（Claude）  
  - Google Gemini  
  - xAI Grok  
  - DeepSeek  
  - OpenRouter  
  - Ollama（本地模型）  
  - 及其他兼容 OpenAI 接口的端点

- **移动优先设计**  
  界面简洁直观，专为触摸屏从零构建——无桌面端的笨重感，文字清晰易读。

- **注重隐私，本地存储**  
  你的角色卡、API 密钥、聊天记录及设置**仅存储在本设备上**。  
  我们的服务器不会接收任何上传数据。卸载应用后所有数据随之删除。

- **核心体验完全免费**  
  基础聊天、导入角色以及使用自有 API 密钥均无需付费。

- **离线支持**  
  使用本地模型（通过兼容 Ollama 的端点）可实现完全私密、无需联网的聊天。

## 为什么选择 MiniTavern Android 版？

传统 SillyTavern 设置功能强大，但以桌面端为主，通常需要繁琐的技术配置。  
MiniTavern 消除了这些门槛——无需 Root、无需 Termux、无需 Linux 模拟器、无需端口转发。  
只需安装、导入角色（或使用内置示例）、填入 API 密钥（或使用免费额度），即可开始聊天。
